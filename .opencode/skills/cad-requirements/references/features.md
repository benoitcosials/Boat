# Feature Types Catalog

Every geometric feature on a mechanical part falls into one of these types.
Use these exact type names in `spec.json` — the QA validator checks against this list.

## Structural Features

### bore
A cylindrical through-hole or blind hole for a shaft or pin.
- **Required dimensions**: `diameter`
- **Optional**: `depth` (if blind; through = part thickness)
- **Example**: `{"type": "bore", "diameter": 10.0, "depth": 25.0, "label": "input_shaft"}`

### mounting_hole
A hole for a fastener (screw, bolt). Usually through, often repeated.
- **Required dimensions**: `diameter`
- **Optional**: `count` (number of identical holes), `depth`
- **Example**: `{"type": "mounting_hole", "diameter": 5.0, "count": 4, "label": "corner_mounts"}`

### pocket
A blind rectangular or circular cavity, milled into a surface.
- **Required dimensions**: `length`, `width`, `depth` (or `diameter` + `depth` for circular)
- **Example**: `{"type": "pocket", "length": 30.0, "width": 20.0, "depth": 5.0, "label": "bearing_seat"}`

### slot
An elongated cutout (through or blind), like a keyway or adjustment slot.
- **Required dimensions**: `length`, `width`, `depth`
- **Example**: `{"type": "slot", "length": 15.0, "width": 4.0, "depth": 3.0, "label": "keyway"}`

## Edge Treatments

### chamfer
A beveled edge, typically 45°, to break sharp corners or guide insertion.
- **Required dimensions**: `width` (chamfer distance from edge) or `radius` for round chamfers
- **Example**: `{"type": "chamfer", "width": 1.0, "label": "lead_in_chamfer"}`

### fillet
A rounded internal or external corner to reduce stress concentration.
- **Required dimensions**: `radius`
- **Example**: `{"type": "fillet", "radius": 3.0, "label": "corner_reinforcement"}`

## Connection Features

### thread
A helical thread for screws (internal or external).
- **Required dimensions**: `diameter` (nominal), `depth` (thread engagement length)
- **Example**: `{"type": "thread", "diameter": 6.0, "depth": 12.0, "label": "M6_mount"}`

### groove
A circumferential or linear recess (for O-rings, circlips, or alignment).
- **Required dimensions**: `width`, `depth`
- **Optional**: `diameter` (for circular grooves)
- **Example**: `{"type": "groove", "width": 2.0, "depth": 1.0, "diameter": 25.0, "label": "o_ring_groove"}`

### keyway
A rectangular slot for a key (transmits torque between shaft and hub).
- **Required dimensions**: `length`, `width`, `depth`
- **Example**: `{"type": "keyway", "length": 20.0, "width": 4.0, "depth": 2.5, "label": "shaft_keyway"}`

## Reinforcement Features

### boss
A raised cylindrical pad around a hole for added thickness (bearing seat, screw boss).
- **Required dimensions**: `diameter`, `height`
- **Example**: `{"type": "boss", "diameter": 15.0, "height": 5.0, "label": "screw_boss"}`

### rib
A thin wall or gusset for structural reinforcement.
- **Required dimensions**: `length`, `height`, `width` (rib thickness)
- **Example**: `{"type": "rib", "length": 40.0, "height": 15.0, "width": 3.0, "label": "corner_gusset"}`

### flange
A projecting flat rim or edge for mounting or sealing.
- **Required dimensions**: `width` (flange projection), `height` (flange thickness)
- **Example**: `{"type": "flange", "width": 10.0, "height": 5.0, "label": "mounting_flange"}`

## Motion Features

### gear
An involute spur gear profile (teeth generated by the engineering stage).
- **Required dimensions**: none at spec stage (teeth count, module come from engineering)
- **Note**: The `gear` type in spec means "this part has gear teeth" — the actual
  parameters are computed in the engineering stage.
- **Example**: `{"type": "gear", "label": "output_gear"}`

### spline
A series of ridges or teeth on a shaft for torque transmission.
- **Required dimensions**: `diameter`, `count`
- **Example**: `{"type": "spline", "diameter": 20.0, "count": 8, "label": "shaft_spline"}`

## When to Ask for Clarification

- **User says "a hole"** → ask: "Is this for a shaft (bore), a screw (mounting_hole), or something else?"
- **User says "rounded corners"** → ask: "Internal corners (fillet) or external edges (chamfer)?"
- **User says "reinforcement"** → ask: "Ribs, gussets, or thicker walls?"
- **User says "a cutout"** → ask: "Through (pocket with depth=thickness) or blind (shallow pocket)?"
